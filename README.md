# The Bridge Club — демоверсия сайта

Учебный проект: адаптивный двуязычный сайт международного сообщества The Bridge Club в Москве.

**Открыть демо:** https://the-bridge-club-moscow.andramida2008.chatgpt.site/

## Возможности

- Английская и русская версии с переключением языка на той же странице.
- 20 страниц на каждом языке: главная, события, сообщество, участники и спикеры, партнёры, информация о клубе и тематические истории.
- Адаптивная вёрстка для компьютеров и мобильных устройств.
- Фоновое видео без звука с автоматическим воспроизведением, повторением и изображением-заставкой.
- Каталог людей с фильтрацией и профилями.
- Ссылки на регистрацию через Timepad и сообщество в Telegram.

## Исходники и запуск

Скачайте и распакуйте `the-bridge-source.zip` в отдельную папку. В эту же папку распакуйте три архива с видео: `video-backgrounds.zip`, `video-report-1.zip` и `video-report-2.zip`. Каждый архив — обычный ZIP; при распаковке сохраните структуру вложенных папок. Видео вынесены отдельно из-за ограничения размера загрузки в веб-интерфейсе GitHub. Все видео, используемые сайтом, включены; неиспользуемый исходный монтаж исключён. Затем откройте папку проекта в терминале. Нужен Node.js 20 или новее.

```sh
npm ci
npm run build
npm run check
node scripts/preview.mjs
```

Откройте http://127.0.0.1:4173/ . Русская версия доступна по адресу http://127.0.0.1:4173/ru/ .

## Структура проекта

- `content/ru/` — редактируемые тексты и HTML русской версии.
- `scripts/build-languages.mjs` — сборка обеих языковых версий.
- `scripts/translation-map.mjs` — английские переводы.
- `dist/` — готовый сайт, стили, скрипты, фотографии и видео.
- `dist/data/people.json` — данные каталога людей.
- `scripts/check-site.mjs` — проверка страниц, внутренних ссылок, ресурсов и главных кнопок.

Сборка формирует английскую версию в корне сайта и русскую в `/ru/`. Готовые страницы в `dist/` генерируются из исходников.

## Технологии и границы демоверсии

HTML, CSS, JavaScript, Node.js и Cheerio. Статический сайт, без собственной базы данных. Админка и интеграция CRM запланированы и в этой версии не реализованы. Страница платформы является концепцией. Даты мероприятий отражают демонстрационное содержание проекта.

Фотографии, видео и фирменные материалы относятся к The Bridge Club и предоставлены для проекта. Репозиторий не предоставляет отдельную лицензию на их повторное использование.
